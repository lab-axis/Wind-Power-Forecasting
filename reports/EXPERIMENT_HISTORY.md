## ARIMA·확률 LightGBM 확장 (2026-10-04)

추가 실행 `probabilistic_extension_20261004T121114+0900`에서 ARIMA, 24h 점예측 LightGBM, 직접 분위수 LightGBM, 허들 분위수 LightGBM을 평가했습니다. 기존 모델 결과를 유지한 14개 모델 × 6개 시계의 확장 표를 별도로 저장했습니다. 기존 체크포인트와 기존 CSV는 덮어쓰지 않았습니다.

신규 모델은 검증 CRPS로 선택했고 기존 신경망은 기존 검증 손실 기준 체크포인트를 재사용했습니다. 단위·통합 검증 23개, 평가 84행의 지표·시점·해시 확인, 신규 모델 24개 조합의 재로딩 검증을 통과했습니다. EMFN은 +1h/+3h/+9h에서 확장 본문 비교군 중 최저 CRPS였으나, 허들 분위수 LightGBM의 영발전 Brier는 6개 시계 모두 EMFN보다 낮았습니다. 이 단계에서는 다중 시드와 블록 단위 불확실성 검증을 수행하지 않았으며, 다음 절의 후속 실행에서 완료했습니다.

## 검증 CRPS 선택 통일 및 3개 시드 (2026-10-04)

실행 `crps_multiseed_20261004T175005+0900`에서 당시 본문 후보 6개 모델·6개 시계와 시드 42·2026·3407을 고정했습니다. 신경망 36개와 LightGBM 54개를 새로 학습했고, 이미 검증 CRPS로 선택한 ARIMA의 6개 시계 결과를 재사용했습니다. 선택 차수는 2종이며 시드별 반복 적합을 하지 않았습니다. 신경망 선택·조기 종료와 EMFN 학습률 스케줄러가 검증 CRPS를 사용하며 학습 손실은 유지합니다. 따라서 이전 실행 대비 차이를 체크포인트 선택만의 효과로 분리하지 않습니다.

32개 테스트, 192개 검증/평가 지표 재계산, 모든 모델 조합의 체크포인트 재로딩 및 타임스탬프·해시 확인을 통과했습니다. 별도 재검증 프로세스의 cuDNN TF32 기본값 차이를 진단하여 학습 설정과 일치시켰고, 검증 허용오차를 완화하지 않았습니다. LightGBM 세 시드의 모든 저장 예측은 동일했습니다.

6개 시계 평균 CRPS는 EMFN 1.4642 ± 0.0126, 허들 분위수 LightGBM 1.4607입니다. EMFN의 최저 평균 CRPS 시계는 +1h/+3h이며, 허들 LightGBM의 Brier 평균이 6개 시계 모두 더 낮습니다. 24h/168h paired 시간 블록 구간을 함께 기록했고, 허들 LightGBM 대비 EMFN의 +3h CRPS 차이 구간은 두 블록 길이 모두 음수였습니다. 이는 개발 기간의 탐색적 결과로 한정합니다.

[다중 시드 결과와 재현 명령](multiseed_crps_results.md), [검증 결과](multiseed_crps_validation.json), [분석 산출물 해시](multiseed_analysis_provenance.json)를 참고하십시오. 기존 단일 시드 표·고정 경로 가중치는 덮어쓰지 않았습니다. 과거 10개 모델/구조 어블레이션 재현 진입점은 기존 loss 선택을 명시적으로 고정하여 새 기준과 혼용하지 않습니다.

## 문서·코드 정합성 및 논문 배치 정리 (2026-10-05)

README와 연구 계획을 단계별 완료 범위, 현재 결과, 남은 과제로 재구성했습니다. 이전 단일 시드 규약을 최신 다중 시드 규약처럼 읽을 수 있던 부분, 168h/24h LightGBM 구분, CSV별 `mae_mean` 의미, 기존 가중치와 최신 시드별 체크포인트 위치를 명시했습니다. 생성형 보고서의 템플릿도 함께 고쳐 다시 생성할 때 과거 본문 구성안이 현재 확정안으로 돌아오지 않도록 했습니다.

사용자의 표준 모델 중심 본문 선호를 반영하여 `configs/paper_presentation.yaml`을 학습 설정과 분리했습니다. 현재 표시용 본문은 EMFN·ARIMA·CNN-LSTM·일반 LightGBM(24h), 보조 확률 표는 EMFN·직접 분위수·허들 분위수 LightGBM입니다. 최대 비교 모델 수는 상한이며, Persistence는 추가 후보로 남겼습니다. 이 배치 결정은 결과 확인 이후의 편집 결정입니다. 완료된 실행의 모델 목록이나 사전 설정으로 소급하지 않습니다.

새 `export_paper_views`는 검증된 시드 요약의 행만 추출합니다. 학습·재평가·결과 삭제 없이 본문용 24행과 보조용 18행을 생성했습니다. 기존 전체 결과와 단일 시드 축약 표는 보존했습니다. 이전 생성 보고서·분석 소스 ZIP·해시 기록은 로컬 `.experiment_archive/documentation_alignment_20261005/`에 보관했습니다.

CNN-LSTM의 YAML `cnn_lstm_patience`가 트레이너에 전달되지 않던 불일치를 수정했습니다. 기존 설정과 코드 상수는 모두 5였으므로 완료된 실험 수치는 바뀌지 않습니다. 앞으로는 설정값이 실제 조기 종료에 적용되며, 기존 체크포인트로 추가 재학습을 하지 않았습니다.

과거 그림 재생성기가 공용 그림 폴더 전체를 해당 실행의 manifest에 넣고, 로컬 아카이브가 없는 환경에서 최신 그림까지 옮길 수 있는 동작도 수정했습니다. 이제 자신이 생성한 그림만 기록하고 다른 실행의 그림은 이동하지 않습니다. 기존 32개 테스트에 patience 적용 검증을 추가한 33개 테스트와 노트북 실행을 통과했습니다. [문서 정합성 검증](documentation_consistency_validation.json)에 기존 결과 보존 및 표시용 표 대조 결과를 기록했습니다.
