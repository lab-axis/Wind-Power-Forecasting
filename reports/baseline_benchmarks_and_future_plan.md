## 현재 논문 배치안

사용자가 요청한 **표준 모델 중심의 간결한 본문**으로 정리합니다. 이 배치안은 결과를 확인한 뒤 조정한 편집 결정이며 실험 전에 고정한 것처럼 소급하지 않습니다. 기존 실행의 모델 목록·설정·결과는 수정하지 않습니다.

| 위치 | 현재 준비된 모델 | 역할 |
|---|---|---|
| 본문 주요 표 | EMFN, Naive Persistence, ARIMA, LSTM, 일반 LightGBM(24h) | 총 5개 모델; +1h/+6h/+24h 표, 6개 시계 전체 곡선 |
| 부록/보조 확률 표 | EMFN, 분위수 LightGBM, 허들 분위수 LightGBM | 예측분포와 영발전 확률의 경쟁력·한계 검토 |
| 전체 결과 보존 | CNN-LSTM 등 최신 15개 모델, 시드별 모든 지표; 이전 실행 별도 보존 | 모델·입력 예산·선택 기준을 명시하여 별도 제공 |

이번 배치안은 제안 모델 포함 5개이며 LightGBM은 본문에서 한 모델만 표시합니다. 다른 단계의 LSTM/TCN 결과를 혼합하지 않고 최신 재실험의 행만 사용합니다. [표시 설정](../configs/paper_presentation.yaml)은 학습 설정과 분리되어 있고, [본문 표](tables/paper_main_standard_baselines.csv), [대표 시계 축약](tables/paper_main_compact.csv), [보조 확률 표](tables/paper_supplementary_probability.csv)를 생성합니다.

본문에서 확률 비교를 모두 삭제하고 우월성만 주장하지 않습니다. 핵심 관찰과 한계를 요약하고 부록을 참조합니다. 불리한 결과를 지우거나 좋은 시드만 선택하지 않습니다. 분위수 LightGBM은 기본 quantile 목적함수를 사용하지만 분포 구성 후처리가 있고, 허들 LightGBM은 분류+양수 조건부 분위수라는 추가 구조가 있으므로 보조 구조 비교로 해석합니다.

## 지표와 모델 선택 기준

| 역할 | 지표 | 출력 |
|---|---|---|
| 주 지표 | CRPS ↓ | 전체 예측분포; 결정론 모델은 Dirac CRPS=MAE |
| 핵심 보조 | 영발전 Brier ↓ | P(Y=0); 확률 출력이 없으면 N/A |
| 점예측 | RMSE ↓ | 확률 모델의 평균 또는 결정론 자체 점출력 |
| 점예측 | MAE ↓ | 확률 모델의 중앙값 또는 결정론 자체 점출력 |
| 영발전 판별 | 영발전 AUPRC ↑ | 영발전 확률의 순위 판별력; 없으면 N/A |

확률 출력이 없는 기준선만으로 CRPS가 좋아졌다는 사실은 확률 모형 전체에 대한 우월성을 입증하지 않습니다. 보정은 Brier·ECE·구간 폭·coverage를 함께 봅니다. 점질량을 포함한 구간의 포함률이 명목 90%와 정확히 일치해야만 좋은 것은 아닙니다.

신경망 기본 선택·조기 종료는 검증 CRPS이며 EMFN 학습률 스케줄러도 같은 지표를 관찰합니다. 학습 목적함수는 기존 composite/Huber를 유지합니다. 최신 전체 실험은 `run_all_baselines`로 실행합니다. `run_multiseed_crps`는 이전 6개 모델 실행용입니다. 과거 10개 모델/구조 어블레이션의 legacy 진입점은 loss 선택이므로 혼용하지 않습니다. 학습 예산·입력 구조가 완전히 같은 아키텍처 비교는 아닙니다.

CSV 열은 다음처럼 구분합니다.

- 기존 10개 모델의 `mae`: EMFN 평균 예측의 오차. 중앙값은 `mae_median`.
- 확장/다중 시드의 개별 지표 CSV `mae`: 확률 모델 중앙값의 오차. `mae_mean`: 분포 평균 예측의 오차.
- 이전 축약 표 `paper_five_comparators.csv`: 중앙값 MAE만 발췌하며 `mae_mean` 열은 없음. 파일명은 이전 구성안이고 최신 표를 뜻하지 않음.
- `multiseed_crps_summary.csv`와 현재 표시용 표의 `mae_mean`: **중앙값 MAE의 시드 평균**. `_mean`/`_sd`는 시드 집계 접미사이며 분포의 평균/중앙값 선택과 다름.
- 최신 `all_baselines_metrics.csv`와 `all_baselines_summary.csv`도 각각 같은 개별/요약 규칙입니다. `nmae_pct`는 확률 모델의 평균 예측에 기반하므로 중앙값 MAE를 정규화한 값과 다를 수 있습니다.

## 현재 결과의 해석

EMFN의 6개 시계 평균 CRPS는 1.4642 ± 0.0126, 직접 분위수 LightGBM은 1.4689, 허들 분위수 LightGBM은 1.4607입니다. EMFN은 +1h/+3h에서 최저 평균 CRPS였고, 허들 LightGBM의 평균 Brier가 6개 시계 모두 더 낮았습니다. 이 관찰은 전체 재실험에서도 유지됐습니다. 이전 6개 모델 실행의 블록 구간은 그 실행에 대한 탐색적 분석이며 최신 실행의 검정 결과로 대체 사용하지 않습니다.

전반적인 확률 예측 우월성은 확인되지 않았습니다. 본문 표준 모델 비교와 별개로 이 관찰을 유지합니다. CRPS 선택으로 학습률 경로도 바뀌었으므로 이전 실행과의 차이를 체크포인트 선택만의 효과로 분리할 수 없습니다.

이전 GRU는 일부 시계에서 상수 0으로 수렴했습니다. 마지막 ReLU가 음수 초기 출력에서 기울기를 차단하는 경로를 제거해 선형 출력으로 새로 학습했고, 최신 전체 실행의 검증 상수 예측 경고는 0개입니다. 실패한 과거 실행을 GRU 일반의 성능으로 해석하지 않습니다. Prophet은 기존 train-only 계절·추세 설정을 유지한 점예측이며 rolling refit이나 미래 관측 기상을 쓰지 않습니다. 학습 기간이 2년 미만이라 연간 계절성 식별의 한계가 있습니다.

기존 regression_mode는 Route B와 gate도 제거하므로 순수 head 대조군이 아닙니다. 기상 제거도 입력 차원·gate가 함께 달라지는 패키지 수준의 진단입니다.

## 다음 연구 과제

1. 최신 본문/부록 표와 5개 노트북을 기반으로 초안을 작성합니다. Persistence 추가와 전체 베이스라인 재실험은 완료됐습니다. 주 지표를 유리한 결과에 맞춰 변경하지 않습니다.
2. 같은 특징 표현 h의 Linear+clipping / C×sigmoid / Hurdle 출력을 비교합니다. 백본을 재학습하는 실험과 h를 고정해 헤드만 학습하는 실험을 구분합니다. 기존 regression_mode로 대체하지 않습니다.
3. 기상군·gate·HF/AR 경로의 기여를 검증 기간과 다중 시드로 점검합니다. 조건부 예측 정보와 인과 효과를 구분하고, 시간 의존성을 무시한 행 셔플로 효과를 과장하지 않습니다.
4. 검증 구간 rolling-origin, 계절·풍속군별 calibration, 분위수 격자·끝점 보간·결측 처리 민감도를 검토합니다. 보정이나 설계 선택은 검증 구간에서 수행합니다.
5. 최종 설계 고정 후 성능 선택에 미사용한 기간/발전소로 평가합니다. 이미 학습·튜닝에 사용한 2024 블록을 다시 숨기는 것은 독립 검증이 아닙니다. 2026년 분 단위 AWS는 이미 있으며 2025년 중복 자료로 시간 변환을 검증했습니다. 별도 기상 후보를 기존 데이터와 합치거나 2026년 예측 점수를 내지는 않았습니다.

2026-10-05 후속 작업에서 기존 예측의 층별 진단과 7종 구조 대조군 준비를 추가했습니다. [완료 범위와 미완료 과제](research_readiness_20261005.md)를 참조하십시오. 3개 시드 × 6개 시계 × 7개 변형의 126개 실제 학습은 아직 수행하지 않았으며, 고정된 동일 h에 대한 head-only 실험과 rolling-origin도 남아 있습니다.

## 외부 명세 확인이 필요한 사항

문서 정리와 현재 코드 실행을 막는 질문은 없습니다. 다음은 데이터 파일만으로 확정할 수 없습니다.

- 발전량 단위와 01시/24시 집계 구간. 공식 페이지는 송전량으로 설명하지만 본문은 kWh, 컬럼 정의는 MWh입니다. 사용자는 별도 기관 설명을 받은 적이 없다고 확인했습니다. 기존의 2025-02-01 이전 Wh·이후 kWh 가정 및 구체적인 계량 경계는 공식 확인 필요.
- 발전량·AWS의 배포 지연 및 예측 발행 시각. 현재는 시간 구간 종료 즉시 관측이 가용한 오프라인 가정.
- 21 MW 정격의 기간 내 고정 여부, 정비·부분 가동·출력제어 이력. 공식 설명은 0을 실제 무발전으로 안내하지만 원인별 운전 상태를 제공하지 않습니다.
- 2026년 1~3월은 사용자 확인상 기술통계 열람만 했고 성능 평가·선택에는 사용하지 않은 후보 기간입니다. 다른 발전소 자료는 없습니다. 운영 예측 시계 중요도·오차 비용은 미확정입니다.

실측 터빈 풍속·제어 상태가 확보되기 전에는 관측소 풍속에 제조사 cut-in/out 제약을 직접 적용하지 않습니다. 현재 모델은 [0,21]의 유계와 영발전 질량을 반영한 통계 모형이며 실제 제어 법칙을 내장한 것은 아닙니다.
