# 벤치마크 현황과 논문 구성·후속 연구 계획

정리 기준일: **2026-10-05**. 현재 문서의 구성 결정과 완료된 실험 당시의 설정을 구분합니다. 실행별 수치는 [실험 이력](EXPERIMENT_HISTORY.md), [단일 시드 확장](probabilistic_baselines.md), [다중 시드 결과](multiseed_crps_results.md)에 보존합니다.

## 완료한 작업

| 단계 | 실제 완료 범위 | 아직 주장할 수 없는 것 |
|---|---|---|
| 오류 수정 | 고정 MWh 정규화, ECE 인자, raw 출력 보존, persistence 정렬, 공통 시점, 과거값 결측 처리, 버전 문서 교정 | 과거 실험 수치의 자동 정당화 |
| 수정 실행 | 10개 모델 × 6개 시계, seed 42; 구조 변형 4개 × 2개 시계 | 순수 출력 헤드 효과, 모든 모델의 정상 학습 |
| 확률 확장 | ARIMA·24h 점예측/분위수/허들 분위수 LightGBM 추가, 84개 평가 행 | 당시 기존 신경망까지 CRPS로 선택했다는 주장 |
| CRPS·다중 시드 | 6개 모델군, 6개 시계; 신경망 36개·트리 54개 학습, ARIMA 6개 시계 선택 결과 재사용 | 다른 신경망·구조 어블레이션 전체의 다중 시드 완료 |
| 불확실성·재현 확인 | 시드 SD, 24h/168h paired 블록 구간, 192개 지표 행 및 모든 체크포인트 조합 검증 | 블라인드 독립 검증, 다중 비교·비정상성을 해결한 확증적 검정 |

3개 시드는 42·2026·3407입니다. LightGBM의 현재 설정에서는 모든 시드의 저장 예측이 같았으므로 SD=0을 일반적인 안정성 우월성으로 해석하지 않습니다. ARIMA는 시드 반복 적합을 하지 않았고 6개 시계에서 선택된 차수는 2종입니다. 신경망은 시드별 학습의 점수를 평균했으며 예측을 합친 앙상블이 아닙니다.

## 현재 논문 배치안

사용자가 요청한 **표준 모델 중심의 간결한 본문**으로 정리합니다. 이 배치안은 결과를 확인한 뒤 조정한 편집 결정이며 실험 전에 고정한 것처럼 소급하지 않습니다. 기존 실행의 모델 목록·설정·결과는 수정하지 않습니다.

| 위치 | 현재 준비된 모델 | 역할 |
|---|---|---|
| 본문 주요 표 | EMFN, ARIMA, CNN-LSTM, 일반 LightGBM(24h) | 제안 모델과 고전 시계열·신경망·트리 기준선 비교 |
| 부록/보조 확률 표 | EMFN, 분위수 LightGBM, 허들 분위수 LightGBM | 예측분포와 영발전 확률의 경쟁력·한계 검토 |
| 추가 후보 | Naive Persistence | 단순 기준선; 이전 표에 있으나 현재 표에는 아직 합치지 않음 |
| 전체 결과 보존 | 이전 10/14개 모델, 시드별 결과, 구조 어블레이션 | 모델·입력 예산·선택 기준을 명시하여 별도 제공 |

비교 모델 최대 5개는 상한으로 해석합니다. 현재 통일 조건으로 준비된 표준 비교군은 3개이며, 수를 채우기 위해 다른 단계의 LSTM/TCN 결과를 임의로 혼합하지 않습니다. 최종 투고 모델 수는 아직 확정되지 않았습니다. [표시 설정](../configs/paper_presentation.yaml)은 학습 설정과 분리되어 있고, [본문 표](tables/paper_main_standard_baselines.csv)와 [보조 확률 표](tables/paper_supplementary_probability.csv)는 검증된 다중 시드 요약의 행만 추출합니다.

본문에서 확률 비교를 모두 삭제하고 우월성만 주장하지 않습니다. 핵심 관찰과 한계를 요약하고 부록을 참조합니다. 불리한 결과를 지우거나 좋은 시드만 선택하지 않습니다. 분위수 LightGBM은 기본 quantile 목적함수를 사용하지만 분포 구성 후처리가 있고, 허들 LightGBM은 분류+양수 조건부 분위수라는 추가 구조가 있으므로 보조 구조 비교로 해석합니다.

## 지표와 모델 선택 기준

| 역할 | 지표 | 출력 |
|---|---|---|
| 주 지표 | CRPS ↓ | 전체 예측분포; 결정론 모델은 Dirac CRPS=MAE |
| 핵심 보조 | 영발전 Brier ↓ | P(Y=0); 확률 출력이 없으면 N/A |
| 점예측 | RMSE ↓ | 확률 모델의 평균 또는 결정론 자체 점출력 |
| 점예측 | MAE ↓ | 확률 모델의 중앙값 또는 결정론 자체 점출력 |
| 영발전 판별 | 영발전 AUPRC ↑ | 영발전 확률의 순위 판별력; 없으면 N/A |

확률 출력이 없는 기준선만으로 CRPS가 좋아졌다는 사실은 확률 모형 전체에 대한 우월성을 입증하지 않습니다. 보정은 Brier·ECE·구간 폭·coverage를 함께 봅니다. 점질량을 포함한 구간의 포함률이 명목 90%와 정확히 일치해야만 좋은 것은 아닙니다.

신경망 기본 선택·조기 종료는 검증 CRPS이며 EMFN 학습률 스케줄러도 같은 지표를 관찰합니다. 학습 목적함수는 기존 composite/Huber를 유지합니다. 과거 10개 모델 및 구조 어블레이션 재현 진입점만 loss 선택을 명시합니다. 현재 6개 모델 실험은 `run_multiseed_crps`로 실행합니다. 학습 예산·입력 구조가 완전히 같은 아키텍처 비교는 아닙니다.

CSV 열은 다음처럼 구분합니다.

- 기존 10개 모델의 `mae`: EMFN 평균 예측의 오차. 중앙값은 `mae_median`.
- 확장/다중 시드의 개별 지표 CSV `mae`: 확률 모델 중앙값의 오차. `mae_mean`: 분포 평균 예측의 오차.
- 이전 축약 표 `paper_five_comparators.csv`: 중앙값 MAE만 발췌하며 `mae_mean` 열은 없음. 파일명은 이전 구성안이고 최신 표를 뜻하지 않음.
- `multiseed_crps_summary.csv`와 현재 표시용 표의 `mae_mean`: **중앙값 MAE의 시드 평균**. `_mean`/`_sd`는 시드 집계 접미사이며 분포의 평균/중앙값 선택과 다름.

## 현재 결과의 해석

EMFN의 6개 시계 평균 CRPS는 1.4642 ± 0.0126, 직접 분위수 LightGBM은 1.4689, 허들 분위수 LightGBM은 1.4607입니다. EMFN은 +1h/+3h에서 최저 평균 CRPS였고, 허들 LightGBM의 평균 Brier가 6개 시계 모두 더 낮았습니다. 허들 LightGBM 대비 EMFN +3h CRPS 차이의 블록 구간은 두 블록 길이 모두 음수였으나 다른 시계 구간은 0을 포함했습니다. 0 포함을 동등성 증명으로 해석하지 않습니다.

전반적인 확률 예측 우월성은 확인되지 않았습니다. 본문 표준 모델 비교와 별개로 이 관찰을 유지합니다. CRPS 선택으로 학습률 경로도 바뀌었으므로 이전 실행과의 차이를 체크포인트 선택만의 효과로 분리할 수 없습니다.

이전 GRU는 +3h/+6h/+12h/+24h에서 상수 0으로 수렴했습니다. 해당 실행의 실패 사례이며 GRU 일반의 성능이 아닙니다. 기존 regression_mode는 Route B와 gate도 제거하므로 순수 head 대조군이 아닙니다. 기상 제거도 입력 차원·gate가 함께 달라지는 패키지 수준의 진단입니다.

## 다음 연구 과제

1. 현재 표의 본문·부록 배치와 필요 시 Persistence 추가를 정리합니다. 기존 결과를 재사용하더라도 타깃/발행 시각·정답·평가 규약을 확인합니다. 주 지표를 유리한 결과에 맞춰 변경하지 않습니다.
2. 같은 특징 표현 h의 Linear+clipping / C×sigmoid / Hurdle 출력을 비교합니다. 백본을 재학습하는 실험과 h를 고정해 헤드만 학습하는 실험을 구분합니다. 기존 regression_mode로 대체하지 않습니다.
3. 기상군·gate·HF/AR 경로의 기여를 검증 기간과 다중 시드로 점검합니다. 조건부 예측 정보와 인과 효과를 구분하고, 시간 의존성을 무시한 행 셔플로 효과를 과장하지 않습니다.
4. 검증 구간 rolling-origin, 계절·풍속군별 calibration, 분위수 격자·끝점 보간·결측 처리 민감도를 검토합니다. 보정이나 설계 선택은 검증 구간에서 수행합니다.
5. 최종 설계 고정 후 미사용 기간/발전소로 독립 검증합니다. 이미 학습·튜닝에 사용한 2024 블록을 다시 숨기는 것은 독립 검증이 아닙니다. 2026년은 실제 기상 수집이 먼저입니다.

## 외부 명세 확인이 필요한 사항

문서 정리와 현재 코드 실행을 막는 질문은 없습니다. 다음은 데이터 파일만으로 확정할 수 없습니다.

- 발전량 공식 단위, 총발전량/송전단 순발전량 구분, 시간대와 01시/24시 집계 구간. 기존의 2025-02-01 이전 Wh·이후 kWh 가정은 공식 확인 필요.
- 발전량·AWS의 배포 지연 및 예측 발행 시각. 현재는 시간 구간 종료 즉시 관측이 가용한 오프라인 가정.
- 21 MW 정격의 기간 내 고정 여부, 정비·부분 가동·출력제어 이력, 0의 결측 대체 여부.
- 미사용 기간/발전소 확보 가능성 및 실제 운영에서의 예측 시계 중요도·오차 비용.

실측 터빈 풍속·제어 상태가 확보되기 전에는 관측소 풍속에 제조사 cut-in/out 제약을 직접 적용하지 않습니다. 현재 모델은 [0,21]의 유계와 영발전 질량을 반영한 통계 모형이며 실제 제어 법칙을 내장한 것은 아닙니다.
