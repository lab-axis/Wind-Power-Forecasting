## 기상 변환 검증

기상청은 시간통계의 정시 기온·습도·기압과 직전 10분 평균 풍향·풍속을 구분합니다. [공식 명세](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=239)

- 기온·습도·현지기압·해면기압: 정시의 분 자료 값을 사용합니다.
- 풍속: `(t-10분, t]`의 10개 유효 분 풍속 평균을 소수 첫째 자리로 반올림합니다.
- 풍향: 같은 구간의 풍속 가중 벡터 평균을 사용합니다. 반올림된 풍속이 0.5m/s 미만이면 시간자료의 정온 코드 0을 적용합니다. 이는 터빈 시동 임계값이 아닙니다.
- 시간 격자를 복원한 뒤 10개 유효 분을 요구하므로 누락된 분을 건너뛰어 더 오래된 값으로 창을 채우지 않습니다. 미래의 분 자료도 사용하지 않습니다.
- 1분 강수량 등은 현재 6개 기상 입력에 포함되지 않아 이번 후보에서 재구성하지 않았습니다.

2025년 짝지어진 유효 시점에서 기온 8,758개, 습도 8,755개, 두 기압 각 8,758개, 풍속·풍향 각 8,749개가 시간자료와 일치했습니다. 원자료가 결측인 시점까지 복원되었다는 의미는 아닙니다. 비교 허용오차는 정시값 1e-9, 반올림된 바람 0.1이지만 실제 최대 오차는 모두 0입니다.

2026년 후보의 발전량 대상 기간은 `2026-01-01 01:00`부터 `2026-03-31 00:00`입니다. 기상 후보는 2,136행이며, 정시 기온·습도·기압은 결측이 없고 `2026-03-19 11:00`의 풍속·풍향 1행이 결측입니다. 이 결측을 채우거나 발전량과 병합하지 않았습니다. 후보의 경로는 `.experiment_archive/holdout_2026/weather_hourly_candidate.parquet`입니다. 후보 생성 자체가 최종 평가 프로토콜의 확정은 아닙니다.

## 기존 예측의 추가 진단

[시드별 결과](tables/forecast_strata_by_seed.csv), [시드 집계](tables/forecast_strata_summary.csv), [영발전 reliability bin](tables/zero_reliability_by_seed.csv)을 추가했습니다. 전체, 계절(DJF/MAM/JJA/SON), 타깃 직전 1시간과 타깃 사이의 영발전 전환, 발행 시점 관측 풍속군으로 나눕니다. 풍속 경계 3·6·12m/s는 진단용 구간이며 물리적 시동·정지 경계가 아닙니다.

CRPS·Brier·중앙값 MAE·평균 RMSE와 함께 90% 구간 포함률, 구간 폭, interval score를 기록합니다. `covered_90_mean`은 0~1 비율이고, `_mean`/`_std`는 개별 학습 실행의 점수를 집계한 값입니다. 시드 예측을 합친 앙상블은 아닙니다. reliability는 고정된 확률 구간 10개이며 빈 구간도 유지합니다.

대표적인 관찰은 다음과 같습니다. 아래는 +3h의 2025년 결과이며 전체 시계·모델·구간은 CSV에 보존합니다.

| 모델 | 전체 CRPS | 90% 포함률 | 평균 구간 폭(MWh) | 봄 포함률 |
|---|---:|---:|---:|---:|
| EMFN | 1.0563 | 89.60% | 5.5613 | 86.59% |
| 허들 분위수 LightGBM | 1.0878 | 91.52% | 6.7919 | 88.81% |

EMFN은 이 시계에서 구간이 좁지만 포함률도 낮습니다. 봄·겨울·가을 CRPS는 허들 LightGBM보다 낮고 여름은 높습니다. 특정 계절이나 시계에 대한 보편적 우월성, 보정 우월성 또는 새로운 유의성 검정의 결과로 해석하지 않습니다. 점질량이 있어 중앙 구간의 포함률이 항상 명목 90%와 일치해야 하는 것도 아닙니다.

2024년 검증 자료는 체크포인트 선택에 이미 사용됐으며 하반기뿐입니다. 계절별 비교에서 여름은 7~8월, 겨울은 12월만 포함합니다. 타깃 전환 구간은 관측 결과로 정의한 사후 진단이며 발행 시점에 이용 가능한 입력도, 그 자체로 조건부 보정 검정도 아닙니다. 이번 분석에 따른 재보정·튜닝은 수행하지 않았습니다.

## 구조 대조군 준비와 아직 하지 않은 실험

[설정](../configs/structural_ablation.yaml)은 시드 42·2026·3407, 시계 1·3·6·9·12·24h, 검증 CRPS 선택, 최대 35 epoch로 정의합니다. 실제 학습은 총 126개이며 **이번에는 수행하지 않았습니다**. 기본 실행은 준비 상태를 기록하고 `--smoke`는 합성 자료만 사용합니다. `--run`에서만 실제 학습을 수행합니다.

| 대조군 | 구분 | 파라미터 수 |
|---|---|---:|
| reference | 현재 EMFN | 121,164 |
| shared_adapter | 두 과제 어댑터 가중치 공유; 두 출력과 보조 특징 유지 | 112,908 |
| no_weather_state_features | 영발전 분기의 기상·과거 영발전 요약 특징 제거; 백본 기상 유지 | 119,324 |
| no_hf_ar | HF와 AR 경로를 함께 제거 | 120,435 |
| common_linear | 공통 표현 구조 + 선형 점출력, 평가 시 clipping | 104,074 |
| common_sigmoid | 같은 공통 표현 구조 + 용량×sigmoid | 104,074 |
| common_hurdle | 같은 공통 표현 구조 + 허들 분포 | 104,204 |

앞의 4개는 구조 비교, 마지막 3개는 출력 방식 비교입니다. 출력 방식 대조군은 초기 특징 표현이 정확히 동일하며 모든 헤드에 기상·상태·HF·AR 특징을 제공합니다. 학습 중 표현은 달라질 수 있습니다. **고정된 동일 h에 헤드만 학습하는 실험은 아직 아닙니다.** 선형/sigmoid는 기존 정규화 Huber, 허들은 기존 NLL+Huber를 사용하므로 출력 분포와 손실의 결합 효과로 해석합니다. 파라미터 수가 완전히 같은 실험도 아닙니다.

준비한 실제 학습 진입점은 2023~2024년 상반기 학습, 2024년 하반기 선택·진단만 사용합니다. 2025·2026 예측을 계산하지 않습니다. 검증에 사용한 자료에서 평가한 값을 독립 성능으로 주장하지 않습니다. 각 실행의 코드·설정·가중치·검증 예측·해시를 새로운 run에 저장하며 기존 v3 체크포인트를 대체하지 않습니다.

## 2026년 자료와 원자료 명세

사용자는 2026년 기술통계와 그림은 열람했으나 예측 성능을 확인하거나 모델·설정 선택에 사용한 적은 없다고 확인했습니다. 이를 **성능 선택에 미사용한 후속 기간 후보**로 기록하며 완전 블라인드나 다른 발전소의 외부 평가로 부르지 않습니다.

원자료 기준 2026년 89일은 2,136시간, 유효 발전량은 2,064시간입니다. 기준일 1월 31일·2월 3일·2월 15일에 각각 24시간씩, 총 72시간이 결측입니다. 달력 연도 필터에는 `2025-12-31 24시`가 들어가 전체 2,137시간·유효 2,065시간이 됩니다. 영발전은 원자료 기준 177/2,064(약 8.58%)입니다. 과거의 “72시간 연속 결측 3회, 2,137시간 통신 두절” 설명은 잘못됐으며 원인도 확인되지 않았습니다. 보존된 과거 스냅샷을 덮어쓰지 않고 이 정정 기록을 남깁니다.

사용자는 단위·집계 구간에 대해 별도로 받은 기관 설명이 없다고 확인했습니다. [공식 데이터 설명](https://www.data.go.kr/data/15119454/fileData.do)은 송전량으로 기술하면서 본문은 kWh, 컬럼 정의는 MWh로 상충합니다. 0은 실제 무발전이라는 안내가 있지만 개별 0의 정비·제어 등 원인을 판별할 자료는 없습니다. 코드의 2025-02-01 이전 Wh·이후 kWh 가정, 01시/24시 집계 경계, 구체적인 계량 경계 및 관측 가용 지연은 확정하지 않았습니다.

최종 2026 평가 전에는 단위 가정의 처리, 기상 변환·결측·입력 창, 모델·시드·체크포인트·스케일러, 시계·지표·표본 규칙, 재학습 여부를 고정하고 해시를 보존해야 합니다. 과거 2025년 말 관측을 2026년 초 입력에 쓸지, 2026년 관측으로 순차 입력만 갱신할지도 명시해야 합니다. 결과를 본 뒤 유리한 규칙으로 바꾸지 않습니다. 동일 규칙의 재현 확인은 가능합니다.

## 재현 명령

저장소 루트의 기존 호환 런타임에서 실행합니다.

```powershell
$env:PYTHONPATH = Join-Path $PWD '.experiment_archive/python_runtime'
python -m unittest discover -s test -p 'test_*.py'
python -m src.experiments.audit_aws_reconstruction
python -m src.experiments.diagnose_saved_forecasts
python -m src.experiments.prepare_structural_ablation --smoke
# 후속 실제 구조 비교 학습용 명령: 이번 작업에서는 실행하지 않음
python -m src.experiments.prepare_structural_ablation --run
```

남은 작업은 실제 구조 비교 학습, 고정 표현의 head-only 실험, rolling-origin 검증, 원자료 명세 확인 및 최종 평가 규약 확정입니다. 이번 합성 학습 결과는 모델 순위나 성능 근거로 사용하지 않습니다.
